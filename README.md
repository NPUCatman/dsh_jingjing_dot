# 小鲸鱼 · DeepSeek 微信机器人

Windows 微信小号 + DeepSeek API，支持指定好友私聊与指定微信群的文字回复，运行在自己的电脑上，不需要服务器。

当前准备状态：已建立独立 Python 环境，安装依赖并通过离线测试；尚未填写真实 API Key，也尚未在登录小号后验证收发。微信 4.x 的 UI 自动化取决于账号是否提供可访问控件，先通过 `probe` 检测，再实际测试收发。

## 已准备的功能

- 名单里的好友直接发文字即可聊天；指定群里发送 `/鲸鲸 你的问题`，或在开头 `@小鲸鱼` 后空一格提问。推荐用前缀。
- 私聊发送 `/帮助`、`/清空`；群里发送 `/鲸鲸 /帮助`、`/鲸鲸 /清空`。
- 私聊彼此独立，每个群共享一份短期记忆；最多保留最近 10 轮，重启即清空。
- 启动前消息不补回复，只处理启动后新出现且可见的文字；图片、语音、文件暂不处理。
- 默认单会话请求间隔至少 2 秒，期间的新请求会跳过；输入最多 4000 字，回复最多 1000 字。
- Key、聊天名单和虚拟环境均被 Git 忽略；普通运行日志不打印消息正文。

## 第一步：打开项目终端

在 PowerShell 中执行。每条 Python 命令都使用本项目环境，无需激活 Conda 或修改全局 Python。

```powershell
cd D:\ai_work\ai_bot\dsh_jingjing
.\.venv\Scripts\python.exe -m jingjing check
```

本机已经安装依赖，不必重复安装。换电脑或环境损坏时才运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
```

此执行策略仅用于本次脚本进程，不修改系统设置。需要 64 位 Windows 10/11、Python 3.10+。微信依赖固定到具体上游提交及 ZIP SHA-256；本机完整依赖版本保存在 `requirements-lock.txt`。

## 第二步：填写 Key 和聊天名单

```powershell
.\.venv\Scripts\python.exe -m jingjing configure
```

向导依次询问：

1. **DeepSeek API Key**：隐藏输入，粘贴后没有字符显示是正常的，按回车提交。Key 只写入本地 `.env`，不要发到聊天或 GitHub。
2. **好友在小号微信中的完整备注**：例如给自己的大号设置唯一备注“鲸鲸测试员”，在这里填写这个备注。多个名称用逗号分隔。
3. **指定微信群的完整名称**：建议先建一个自己账号参与的小测试群，填写这个群名。

直接回车保留原设置，输入 `-` 清空对应名单。好友和群不能同名；同名好友请先改为唯一备注。名称包含逗号时，直接编辑 `config.json` 的数组。

配置示例（示例名称需要替换）：

```json
{
  "bot_name": "小鲸鱼",
  "friends": ["鲸鲸测试员"],
  "groups": ["小鲸鱼测试群"],
  "group_prefix": "/鲸鲸",
  "cooldown_seconds": 2,
  "max_history_turns": 10,
  "max_input_chars": 4000,
  "max_output_chars": 1000,
  "timeout_seconds": 60
}
```

默认模型 `deepseek-flash` 和接口 `https://api.deepseek.com` 根据 [DeepSeek 当前官方文档](https://api-docs.deepseek.com/) 配置，采用非思考模式。模型在 `.env` 修改，角色性格在 `prompts/system.txt` 修改；修改后重启。

## 第三步：先测试 DeepSeek

```powershell
.\.venv\Scripts\python.exe -m jingjing api-test
```

此命令只发起一次很短的模型请求，正常会显示“小鲸鱼连接成功”。API 按 DeepSeek 实际使用计费，网页/App 会员不能代替 API 余额。

也可先在终端试聊，输入 `/退出` 结束：

```powershell
.\.venv\Scripts\python.exe -m jingjing chat
```

这两种模式均不连接微信。

## 第四步：登录小号并检查微信兼容性

1. 打开已安装的**微信 4.1**，手机扫码登录小号。本机也装有旧版 3.9，本项目默认不连接旧版。
2. 可把小号昵称设为“小鲸鱼”；群内昵称与 `bot_name` 一致才能使用对应的 `@昵称` 文本触发。`/鲸鲸` 不依赖昵称。
3. 小号加自己的大号为好友，加入测试群。用手机先发送普通测试消息，使窗口有可见消息。
4. 在电脑微信左侧会话列表，**双击名单里的好友和群，分别打开独立聊天窗口**。标题必须与配置名称一致。保持普通聊天页面，不进入多选、搜索或历史记录页面。
5. 执行：

```powershell
.\.venv\Scripts\python.exe -m jingjing probe
```

所有目标都显示“通过”再继续。此命令只检测控件，不发消息、不调用 API、不输出聊天正文。“通过”只代表控件可读，下一步还需实际验证收发。

如果无法读取消息列表/输入框，先核对是否登录 4.1 小号、独立窗口已打开、名称完全一致。部分账号无法暴露 UI 树，现有路线无法工作；请保留检测结果再排查。详细来源见 [接入方案与兼容性](docs/接入方案与兼容性.md)。

`probe` 会分别检查微信进程、原生窗口和 UIA 控件。如果显示“已发现 Weixin.exe 进程和可见窗口……但未找到……UIA 窗口”，代表微信确实在运行，不能据此推断未登录。如果你已进入聊天页面仍然出现此结果，当前 UIA 接入还不能工作；重新填写 API Key 或重复运行相同命令不能补出缺失控件。检测和正式运行使用同一套窗口发现逻辑，不会将只有外壳的 Qt 窗口直接当成可发送消息的目标。

## 第五步：先预览，再启用回复

```powershell
.\.venv\Scripts\python.exe -m jingjing run --dry-run
```

启动后从手机大号给小号**新发**“你好”，再到测试群发 `/鲸鲸 你好`。终端应显示回答，微信中不应自动回复。预览会调用真实 API，终端会显示生成内容。

按 `Ctrl+C` 停止预览，正式启动：

```powershell
.\.venv\Scripts\python.exe -m jingjing run
```

重新发送新消息：私聊“你好”、群里 `/鲸鲸 介绍一下你自己`。确认只有名单内聊天有回复，普通群消息不触发，机器人的回复不再次触发。

日后也可用 `start.ps1` 启动。在运行终端按 `Ctrl+C` 停止。请保持电脑开机、网络可用、桌面解锁和微信登录；收发时窗口可能切到前台，不要同时在这些窗口手动输入。程序不修改系统休眠策略。

这是个人微信的桌面自动化接入，微信升级或账号限制可能中断运行。长期运行适合单独电脑或 Windows 虚拟机，无法提供消息送达保证。

## 常见情况

| 情况 | 处理 |
| --- | --- |
| Key 待填写 / 401 | 重新运行 `configure`，使用 DeepSeek 平台生成的 API Key |
| 余额不足 / 402 | 检查 DeepSeek API 账户余额 |
| 模型请求不被接受 | 核对 `.env` 的模型与接口 |
| 找不到聊天窗口 | 双击会话打开独立窗口，核对完整标题、唯一备注、群名 |
| 群里不回复 | 使用 `/鲸鲸 你好`，前缀后加空格 |
| 输入框已有草稿 | 程序会停止；自行保留草稿，清空输入框后重新启动 |
| 发送结果不明确 | 检查微信中是否发出；程序不会自动重发 |
| 已运行另一实例 | 回到原终端 `Ctrl+C` 后再启动 |
| 快速连发漏回复 | 两秒冷却和界面可见范围可能跳过消息，分开发送；不保证高流量完整接收 |

消息只在内存中暂存，重启清空。符合名单与触发条件的消息及上下文会发送到配置的 DeepSeek API。群记忆共享。程序不自动加好友、群发、处理转账或执行聊天中的系统命令。
